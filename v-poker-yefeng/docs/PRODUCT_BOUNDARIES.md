# 产品边界与功能划分

> 版本: v1.0
> 更新日期: 2026-09-18

---

## 一、四端分离架构

| 端 | 域名/路径 | 端口 | 目标用户 | 技术栈 |
|----|-----------|------|----------|--------|
| 玩家端 | goodspage.cn（主站） | 3000 | 玩家 | React + Vite |
| 代理端 | goodspage.cn/agent/ | 8089 | 代理/圈主 | React + Refine |
| 管理端 | goodspage.cn/admin/ | 8088 | 平台管理员 | React + FastAPI-Admin |
| 客服端 | goodspage.cn/support/ | 8090 | 客服人员 | React + Refine |

---

## 二、玩家端功能（Client）

### ✅ 玩家端应该有的功能
1. **账号系统**
   - 玩家注册/登录
   - 忘记密码（后续）
   - 个人信息修改（后续）

2. **大厅系统**
   - 游戏选择（德州/金花/牛牛/三公）
   - 房间列表（公开房间）
   - 创建房间（玩家开房，可选）
   - 加入房间（输入房号 + 密码）

3. **游戏系统**
   - 牌桌界面（座位、公共牌、手牌、底池）
   - 操作按钮（弃牌/过牌/跟注/加注/全下）
   - 倒计时（15 秒，超时自动弃牌/过牌）
   - 结算弹窗（本局输赢、房费、佣金明细）

4. **钱包系统**
   - 余额查询
   - 流水查询
   - 自由转账（玩家间互转，扣 0.01% 手续费）
   - 充值/提现（封闭式经济，暂不开放）

### ❌ 玩家端不应该有的功能
- ❌ 查看代理佣金
- ❌ 管理下级代理
- ❌ 查看全平台数据
- ❌ 管理用户
- ❌ 调整抽水比例

---

## 三、代理端功能（Agent Dashboard）

### ✅ 代理端应该有的功能
1. **账号系统**
   - 代理登录（代理账号由管理员分配）
   - 修改密码（后续）

2. **仪表盘**
   - 累计佣金
   - 下级代理数
   - 总流水
   - 今日新增（后续）

3. **佣金管理**
   - 佣金明细（每局返佣记录）
   - 佣金余额
   - 提现申请（后续）
   - 提现记录（后续）

4. **下级管理**
   - 下级代理列表
   - 代理树（层级关系）
   - 下级流水查询
   - 添加下级代理（后续）

5. **开房管理**（核心！代理主要功能）
   - 创建房间（设置游戏类型、局数、底分）
   - 我的房间列表
   - 房间管理（解散房间、查看在线人数）
   - 房卡消耗记录（房卡模式）

### ❌ 代理端不应该有的功能
- ❌ 玩游戏
- ❌ 查看其他代理的数据
- ❌ 调整平台抽水比例
- ❌ 管理用户账号
- ❌ 查看全平台数据

---

## 四、管理端功能（Admin Dashboard）

### ✅ 管理端应该有的功能
1. **账号系统**
   - 管理员登录
   - 管理员管理

2. **用户管理**
   - 玩家列表
   - 代理列表
   - 客服列表
   - 用户封禁/解封

3. **代理管理**
   - 添加代理
   - 设置代理层级
   - 设置返佣比例
   - 代理树管理

4. **数据看板**
   - 全平台流水
   - 平台留存
   - 活跃玩家数
   - 手续费池余额

5. **系统设置**
   - 抽水比例设置
   - 抽水上限设置
   - 房卡价格设置
   - 游戏开关

### ❌ 管理端不应该有的功能
- ❌ 玩游戏
- ❌ 代替玩家下注

---

### ✅ 客服端应该有的功能

   - 工单列表

## 七、BFF 路由隔离

```
/api/auth/*       → 公开（登录/注册）
/api/rooms/*      → 玩家/代理/管理员（创建房间）
/api/wallet/*     → 玩家（钱包操作）
/api/agent/*      → 代理/管理员（代理后台）
/api/admin/*      → 管理员（管理后台）
/api/support/*    → 客服/管理员（客服后台）
/api/game/*       → 玩家（游戏操作）
```
