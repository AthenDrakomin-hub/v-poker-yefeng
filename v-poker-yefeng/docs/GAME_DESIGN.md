# 棋牌平台游戏设计文档

> 版本: v1.0
> 更新日期: 2026-09-18
> 基于主流棋牌平台市场调研整理

---

## 一、局数设置

### 1.1 平台规则
- 平台后台设定局数范围：**4 - 32 局**
- 代理/房主创建房间时，在此范围内选择具体数字

### 1.2 各游戏默认局数

| 游戏 | 默认局数 | 模式说明 |
|------|----------|----------|
| 德州扑克 | 无限局 | 现金桌模式，玩家可随时加入/离开；SNG 锦标赛有固定盲注递增结构 |
| 炸金花 | 10 局 | 8-12 局常见，10-12 局后结算一次 |
| 牛牛 | 10 局 / 20 局 | 常见 10 局或 20 局，支持 1-20 局自定义 |
| 三公 | 10 局 / 20 局 | 参考牛牛节奏，默认 10 局或 20 局 |

---

## 二、房间创建与准入

### 2.1 谁创建房间
- **代理/房主（圈主）** 是主要创建者（房卡/代理模式）
- 玩家创建公开房间较少，通常由系统自动匹配

### 2.2 房号生成规则
- **6 位随机数字**（行业标准）
- 生成逻辑：随机生成 → 查重 → 循环直到不重复
- 示例：`882341`

### 2.3 密码规则
- 密码为**可选**
- 公开房间：无需密码
- 私人房间（好友房）：设置密码
- 密码格式：0-4 位纯数字
- 空字符串视为公开房间

---

## 三、游戏参数与抽水

### 3.1 底分设置
- 由代理/房主在创建房间时**自定义**
- 平台提供多个场次（初级场、中级场、高级场），每个场次有固定底分范围
- 房主在范围内选择具体底分

### 3.2 抽水规则
- **平台统一制定**，代理不能自行调整
- 两种模式可选：
  - **房卡模式**：代理购买房卡（如 0.3 元/张）后免费开房，平台通过卖房卡盈利
  - **抽水模式**：平台从每局底池按固定比例抽取房费，或按固定金额（如每局 1.5-2 元）收取

### 3.3 抽水上限（德州扑克）
- 每手抽水有上限：**最多 5 个大盲注**
- 防止高额桌抽水过重
- 参数：`big_blind` + `rake_cap_multiplier`（默认 5）

---

## 四、开局与退出规则

### 4.1 最低开局人数

| 游戏 | 最低人数 | 说明 |
|------|----------|------|
| 德州扑克 | 2 人 | Heads-up 即可开始 |
| 炸金花 | 3 人 | 建议 3 人及以上 |
| 牛牛 | 2-6 人 | 2 人可开，6 人最佳 |
| 三公 | 2-6 人 | 2 人可开，6 人最佳 |

### 4.2 中途退出处理
- 已下注的筹码**视为弃权，不予退还**
- 扑克类游戏：玩家断线/逃跑，台面上筹码判给当时牌最大的用户
- 系统将此注视为"弃注"并判负

---

## 五、断线重连

- **标配功能**，提供 **300 秒**重连保护时间
- 玩家掉线后重新登录，可恢复到断线前的牌局状态
- 前端实现：自动重连（最多 5 次，间隔 1 秒）

---

## 六、战绩回放

- 主流平台都提供完整的对局记录保存
- 支持玩家随时复盘
- 部分平台可生成视频文件或牌谱，供玩家回顾和分析
- 当前实现：game_records 表保存游戏流水，settlement_logs 保存分账明细

## 七、房间配置参数表

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| room_id | string | 6位随机 | 房号，查重后分配 |
| room_password | string | "" | 0-4 位数字，空为公开房 |
| game_type | enum | texas_holdem | 游戏类型 |
| total_rounds | int | 10 | 总局数 |
| base_score | int | 100 | 底分 |
| platform_fee_rate | decimal | 0.0500 | 平台抽水率 |
| agent_commission_rate | decimal | 0.0300 | 代理返佣率 |
| min_players | int | 2 | 最低开局人数 |
| max_players | int | 6 | 最大人数 |
| big_blind | int | 100 | 大盲注（德州专用） |
| rake_cap_multiplier | int | 5 | 抽水上限倍数 |
| created_by | string | - | 创建者 ID（代理/房主） |
| room_type | enum | public | public / private |

## 八、资金闭环流程

```
玩家下注 → wallet-service /api/wallet/bet
         玩家钱包 → 牌桌钱包（user_type=room）

一局结束 → wallet-service /api/wallet/game_settle
         牌桌钱包 → 赢家钱包（winners_payout）
         牌桌钱包 → fee_pool（platform_revenue）
         牌桌钱包 → 代理钱包（agent_pool，通过 commission-service 分账）

异常退出 → wallet-service /api/wallet/refund
         牌桌钱包 → 玩家钱包（退还未结算筹码）

能量守恒校验：sum_all_wallets + sum_fee_pool = total_minted
```

## 九、各游戏特殊规则

### 9.1 德州扑克
- 无限注现金桌 / SNG 锦标赛
- 边池计算（all_in 后分层）
- 分池余数分配
- 抽水上限：每手最多 5 个大盲注

### 9.2 炸金花
- 闷牌/看牌倍数差异：闷牌半价，看牌全价
- 比牌动作：第二轮后可发起比牌，输家出局
- 235 反转（可配置，默认关闭）：235 单张通杀豹子

### 9.3 牛牛
- 抢庄模式 + 通比模式
- 牌型倍数：牛牛 4 倍、牛九 3 倍、牛八 2 倍、牛七 2 倍、牛六及以下 1 倍
- 特殊牌型：五花牛、五小牛、炸弹牛

### 9.4 三公
- 抢庄模式 + 通比模式
- J/Q/K 算 0 点
- 三公 > 点数
- 倍数计算同牛牛
