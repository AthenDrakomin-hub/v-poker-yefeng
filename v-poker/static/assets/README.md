# V-POKER 素材标准规范

> 对标 wpk.com / GGPoker 顶级棋牌平台，原子化可复用设计系统。

## 一、卡牌素材标准

| 项目 | 规范 |
|------|------|
| 比例 | 国际桥牌 1:1.4（如 720×1008px） |
| 精度 | 300dpi 印刷级 |
| 圆角 | 精确 2px |
| 分层 | 底纹 / 花色 / 数字 / 边框 4 图层 |
| 分辨率适配 | @1x / @2x / @3x 三档 |
| 命名 | `card_{suit}_{rank}@2x.png`（suit: spade/heart/diamond/club） |

**当前实现**：CSS 矢量绘制（vp-card 组件），无限缩放无锯齿，1:1.4 比例，立体感 box-shadow。

## 二、UI 控件标准

| 项目 | 规范 |
|------|------|
| 按钮厚度 | 8px（md 高度 44px） |
| 圆角 | 12px（round 模式 999px） |
| 高光方向 | 左上角（linear-gradient 180deg 亮色在上） |
| 阴影 | 偏移 2px，`0 2px 8px rgba(0,0,0,0.35)` |
| 描边 | 1px 抗锯齿 |
| 点击反馈 | `scale(0.95) + opacity(0.8)`，150ms |

**当前实现**：vp-button 组件已对齐（渐变高光+阴影+1px描边+scale点击反馈）。

## 三、图标素材标准

| 项目 | 规范 |
|------|------|
| 识别度 | 强剪影，16×16px 下可辨认 |
| 状态变体 | active / inactive / cooldown / disabled |
| 格式 | SVG 矢量优先 |
| 命名 | `icon_{name}_{state}@2x.png` |

## 四、背景纹理标准

| 项目 | 规范 |
|------|------|
| 类型 | 低饱和度噪点 + 渐变 |
| 纹理密度 | ≤10%，不干扰核心内容 |
| 主题 | 赌场级深色黑金 |
| 牌桌 | 真实绒布质感椭圆桌（static/table/ 14张） |

## 五、筹码素材标准

| 项目 | 规范 |
|------|------|
| 颜色 | 紫/红/绿/蓝/金 五档面额 |
| 叠层 | 3-5 层错位堆叠 |
| 动画 | 移动缓动 ease-out，300ms |
| 组件 | vp-chip-stack（CSS 矢量叠层） |

## 六、目录结构

```
static/
├── assets/              # 生产级素材（2x/3x）
│   ├── cards@2x/       # 扑克牌 @2x
│   ├── cards@3x/       # 扑克牌 @3x
│   ├── chips/           # 筹码
│   ├── icons/           # 图标（多状态）
│   ├── buttons/         # 按钮切片
│   └── ui/              # 其他UI控件
├── table/               # 14张游戏桌背景图（真实渲染）
├── cards/               # 扑克牌 PNG（@1x，兼容用）
├── bg/                  # 大厅/MTT背景
├── audio/               # 音效+语音（20+）
└── avatar/              # 荷官头像
```

## 七、8px 网格对齐

所有元素尺寸、间距必须是 8 的倍数，细节可用 4px 倍数：
- 卡片间距：8px / 16px
- 按钮内边距：16px / 24px / 32px
- 座位宽度：96px（12×8）
- 牌桌圆角：40px（5×8）
